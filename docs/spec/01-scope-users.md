# 2. 범위, 사용자 및 핵심 시나리오

> 원본: 통합개발명세서 §2

## 2.1 사용자 유형

| 사용자 | 주요 목표 | 핵심 권한 |
| --- | --- | --- |
| 일반 구독자 | 내 사업장에 필요한 변화와 마감일을 빠르게 확인 | 프로필, 브리핑 조회, 저장, 수신설정 |
| 법인 담당자 | 법인·급여·원천세·지원정책 정보를 조직적으로 관리 | 다중 사업장, 팀 공유, 담당자 설정 |
| 세무전문가 | 원문과 AI 분석을 검토하고 정확한 설명을 승인 | 수정, 승인·반려, 고위험 표시, 정정 |
| 콘텐츠 운영자 | 수집·중복·태그·발송 업무를 운영 | 수집관리, 편집, 예약, 통계 |
| 시스템 관리자 | 계정, 권한, 출처 어댑터와 시스템 설정 관리 | RBAC, 소스레지스트리, 비밀키 제외 설정 |
| B2B 관리자 | 자사 고객에게 화이트라벨 브리핑 제공 | 브랜드, 고객그룹, 발송정책, 성과조회 |

RBAC 역할 매핑은 [11. 보안·개인정보·감사](11-security.md#112-rbac) 참조.

## 2.2 MVP 범위 (In Scope)

- 공식·보조 출처 10~15개 수집 어댑터와 수동 등록
- 원문·첨부파일 저장, 해시, 중복 탐지, 메타데이터 정규화
- 정책 법적 상태 및 콘텐츠 처리 상태 관리
- AI 구조화 추출, 사업자 영향·행동사항 초안 생성
- 전문가 검수·승인·반려·수정 이력
- 사업자 프로필 기반 기본 개인화
- 이메일 발송과 웹 브리핑 화면
- 긴급·일일·주간 발송 유형
- 정정 공지 및 변경 추적
- 관리자 대시보드, 감사로그, 기초 통계

## 2.3 MVP 제외 범위 (Out of Scope)

- 세무 신고서 자동 작성 또는 전자신고 대행
- 개별 납세자의 세액 확정 계산과 법률적 자문 자동화
- 모든 지방자치단체 홈페이지의 완전 자동수집
- 사용자 회계데이터·홈택스 계정 직접 연동
- 앱스토어용 네이티브 앱
- **완전 자동 무검수 발송**
- 복잡한 다국어 서비스와 해외 조세

## 2.4 핵심 유즈케이스

| ID | 시나리오 |
| --- | --- |
| UC-01 신규 정책 탐지 | 운영 스케줄러가 공식기관 목록을 확인하고 신규 게시물과 첨부파일을 수집한다. 시스템은 URL·문서번호·해시를 이용해 신규/변경 여부를 판정한다. |
| UC-02 뉴스에서 공식 원문 찾기 | 전문언론 기사로 이슈를 탐지한 경우 운영자는 연결된 정부 보도자료·입법예고·법령·관보를 검색하여 공식 근거를 연결한다. |
| UC-03 AI 분석과 전문가 검수 | AI가 대상·시행일·변경점·행동사항을 JSON으로 추출한다. 전문가는 원문 증거를 확인해 수정 후 승인한다. |
| UC-04 맞춤 발송 | 승인된 콘텐츠는 사업자 유형·과세유형·업종·지역·직원수·관심세목 기준으로 대상자를 선정해 일일 브리핑으로 발송된다. |
| UC-05 정책 변경 추적 | 발송 후 원문이 수정되거나 하위법령이 공포되면 기존 콘텐츠와 새 버전을 연결하고 변경 영향 대상에게 정정 또는 업데이트 알림을 보낸다. |
| UC-06 세무 상담 전환 | 사용자는 콘텐츠 하단에서 질문 또는 상담신청을 남기고, 세무사무소 CRM 또는 관리자 화면에서 후속 처리한다. |
