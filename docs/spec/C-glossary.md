# 부록 C. 용어집

> 원본: 통합개발명세서 부록 C

| 용어 | 정의 |
| --- | --- |
| **공식 원문** | 법령, 관보, 정부·공공기관이 직접 게시한 공고·보도자료·안내 |
| **정책 클러스터** | 동일 정책의 기사, 보도자료, 예고, 법령, 관보 등을 묶는 단위 |
| **콘텐츠** | 사업자에게 발송되는 가공 정보 |
| **법적 상태** | 논의·발의·예고·통과·공포·시행 등 정책의 **외부** 상태 (`legal_status`) |
| **워크플로 상태** | 탐지·미검증·분석·검수·승인·발송 등 **내부** 처리 상태 (`workflow_status`) |
| **evidence** | 구조화 필드나 문구를 뒷받침하는 **원문 위치** (`source_version_id` + `locator`) |
| **골든셋** | 전문가가 정답을 라벨링한 AI 평가용 사례 집합 |
| **정정** | 오류 또는 정책 변경을 반영한 후속 콘텐츠와 재발송 |
| **멱등성** | 같은 요청을 반복해도 중복 객체·중복 발송이 생기지 않는 특성 |
| **테넌트** | 화이트라벨을 사용하는 개별 세무사무소·기업 고객 단위 |
