# 4. 기능 요구사항

> 원본: 통합개발명세서 §4
> **우선순위**: `MUST` = MVP 인수 필수 · `SHOULD` = MVP 범위 내 우선 구현하되 일정에 따라 조정 · `COULD` = 2단계 후보

`상태` 열은 이 저장소의 구현 진행도다. 스프린트 배정은 [14. 일정·역할·리스크](14-plan-risks.md) 참조.
