## 10.3 콘텐츠 상세 표준 블록 (순서 고정)

1. 상태 배지: 시행 중 / 공포 / 입법예고 / 발의 등
2. 사업자용 제목과 한 줄 요약
3. **내게 해당되는 이유**
4. 현재 적용 기준
5. 변경 또는 예정 내용
6. 시행일·마감일·신청기간
7. 사업자 영향
8. 지금 해야 할 일
9. 전문가 확인이 필요한 항목
10. 공식 출처와 최종 확인시각
11. 정정·업데이트 이력
12. 상담신청

## 10.4 표시 안전 규칙 (UI 불변식)

- 확정되지 않은 상태에는 노란색 경고 문구와 **"시행 확정 아님"** 표시
- **현재 기준과 변경 예정 내용을 같은 문단에 혼합하지 않는다.**
- 시행일이 없으면 **"시행일 확인 필요"**로 표시하고 임의 날짜 금지
- 공식 출처 링크를 접지 않고 상세 화면에서 바로 제공
- AI 생성 여부보다 **전문가 검수 상태를 더 우선적으로** 표시
- 중대한 정정은 기존 콘텐츠 상단에도 배너 표시

> 4·5번 블록의 분리는 §1.3 "상태 분리" 원칙의 UI 표현이다.
> 렌더러가 두 블록을 합치는 템플릿을 만들면 결함으로 취급한다.

### legal_status → 배지 라벨 매핑

| 코드 | 배지 | 색 | 경고 문구 |

| `EFFECTIVE` | 시행 중 | green | — |

| `ASSEMBLY_PASSED` | 국회 통과 | blue | 공포·시행일 확인 필요 |

| `DISCUSSION` | 검토·논의 | gray | 확정 아님 |
