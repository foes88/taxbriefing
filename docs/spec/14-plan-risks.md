# 15. MVP 일정·역할·리스크

> 원본: 통합개발명세서 §15

## 15.1 12주 일정

| 주차 | 주요 산출물 | 스프린트 |
| --- | --- | --- |
| 1~2 | 상세 요구 확정, 화면흐름, 출처 기술조사, 데이터 계약 | S0 |
| 3~4 | 인증·DB·출처 레지스트리·수동등록·객체저장 | **S1** |
| 5~6 | 수집 어댑터, 첨부 처리, 버전·중복·클러스터 | **S2** |
| 7~8 | AI 분석, JSON Schema, 검수 CMS, 근거 연결 | **S2~S3** |
| 9~10 | 사용자 피드, 프로필, 이메일 캠페인, 정정 | **S3** |
| 11 | 통합·보안·성능·데이터 품질 테스트 | S4 |
| 12 | 전문가 UAT, 운영 매뉴얼, 배포, 초기 모니터링 | S4 |

## 15.2 스프린트 백로그

### S1 — 기반과 안전장치 (현재)

| Epic | Story | Acceptance Criteria |
| --- | --- | --- |
| 인증·권한 | JWT 로그인, RBAC 의존성 | 역할 없는 호출은 403, 감사로그 기록 |
| 데이터 기반 | ORM 모델 + Alembic 초기 마이그레이션 | `schema.sql` 대비 누락 테이블 0 |
| 출처 레지스트리 | `GET/POST /sources` | 등급·도메인·수집방식 관리, 중지·재개 |
| 수동 원문 등록 | `POST /raw-contents/manual` | 동일 URL 재등록 시 신규 생성 안 됨 (AT-01) |
| 원문 버전 | 해시 기반 신규/변경/동일 판정 | 본문 변경 시 새 버전 + diff (AT-02) |
| **검증 게이트** | G1~G6 순수 함수 | 뉴스 단독 승인 차단 (AT-03), HIGH 승인 필수 (AT-06) |
| **AI 출력 계약** | Pydantic 모델 + V1~V7 검증 | 근거 없는 날짜는 null (AT-05) |
| 검수 워크플로 | submit-review / reviews | 승인 후 보호필드 수정 시 승인 해제 (AT-07) |
| 멱등성 | `Idempotency-Key` 미들웨어 | 동일 키 재요청은 기존 결과 반환 (AT-09) |
| 개인화 규칙 | 매칭 점수 + 하드 제외 | 제외 대상은 점수 무관 제거 (AT-08) |
| SSRF 방어 | URL 검증기 | 사설 IP 리다이렉트 차단 (AT-14) |
| 감사로그 | append-only 기록 | 승인자·확인 근거 조회 가능 (AT-12) |

**의존성**: 인증 → RBAC → 나머지 전부. 게이트는 DB 없이 독립 개발 가능(순수 함수)이므로 병렬 진행.

### S2 — 수집과 클러스터

| Epic | Story | Acceptance Criteria |
| --- | --- | --- |
| 수집 어댑터 | RSS/HTML/API 어댑터 인터페이스 | 출처 추가 시 코드 변경 없이 등록 |
| 수집 스케줄 | Celery beat + 중복 실행 방지 | 동시 실행 락 (FR-SRC-002) |
| 수집 이력 | `source_runs` 기록 | 실패 원인 조회 (FR-SRC-003) |
| 첨부 처리 | PDF/HWP/DOCX/XLSX 추출 + 악성검사 | 실패 시 원문 링크 유지 (FR-SRC-005) |
| 중복 클러스터 | 1~3차 판정 + 병합 큐 | 애매한 건은 자동 병합 안 함 |
| 테넌트 격리 | 모든 조회에 tenant scope | 교차 조회 불가 (AT-13) |

**의존성**: S1 원문 버전 모델 완료 필요. 첨부 처리는 객체 스토리지 준비 선행.

### S3 — 검수 UI·발송·정정

| Epic | Story | Acceptance Criteria |
| --- | --- | --- |
| 검수 편집기 | A-05 화면 (원문/AI/편집본 3분할) | 근거 클릭 시 원문 위치 이동 |
| 사용자 피드 | `GET /feed` + U-02 | "내게 해당되는 이유" 표시 |
| 이메일 캠페인 | 캠페인 생성·미리보기·예약·발송 | 수신거부 링크 필수 |
| 발송 시점 동의 재확인 | 실행 시점 consent 조회 | 철회자 최종 제외 (AT-10) |
| 정정 센터 | A-08 + 영향 대상 추출 | 영향 대상만 재발송 (AT-11) |
| 킬 스위치 | `POST /admin/delivery-halt` | P1 대응 즉시 발송중지 |

**의존성**: S1 게이트·승인, S2 클러스터. 이메일 공급자 계약 확정 필요(미결 ①).

## 15.3 역할과 투입

| 역할 | 권장 투입 | 책임 |
| --- | --- | --- |
| 제품책임자 | 1 | 우선순위, 의사결정, 인수 |
| 세무전문가 | 1~2 | 상태·해석·골든셋·최종 검수 |
| 백엔드 | 2 | 수집, API, DB, 발송, 보안 |
| 프론트엔드 | 1 | 관리자·사용자 웹 |
| AI/데이터 | 1 | 문서처리, 프롬프트, 평가, 중복 |
| QA | 0.5~1 | 시나리오, 회귀, 데이터 품질 |
| DevOps | 0.5 | CI/CD, 모니터링, 백업 |

## 15.4 리스크

| 리스크 | 영향 | 완화 |
| --- | --- | --- |
| 공식 사이트 구조 변경 | 수집 중단 | 출처별 어댑터 분리, 실패 알림, 수동등록 |
| API·자동수집 이용제한 | 범위 축소 | 사전 이용조건 확인, RSS·메일·수동 대체 |
| HWP·스캔 PDF 추출 실패 | 핵심 조항 누락 | 파일 직접보기, 대체 추출기, 수동 검수 |
| AI 환각·날짜 오인 | 잘못된 발송 | Schema, evidence, null 우선, 전문가 승인 |
| 정책 단계 혼동 | 신뢰 훼손 | 법적상태 enum, A등급 게이트, UI 경고 |
| 저작권 이슈 | 법적 위험 | 뉴스 전문 저장·재배포 최소화, 링크와 자체 요약 |
| 검수 병목 | 발송 지연 | 위험도 큐, SLA, 저위험 템플릿 |
| 발송 채널 심사 지연 | 출시 지연 | 이메일 우선 MVP, 알림톡 병행 준비 |
| 개인정보·광고동의 미비 | 규제 위험 | 법률 검토, 동의 버전·철회 기록 |

## 15.5 개발 착수 체크리스트

- [ ] MVP 출처 10~15개와 수집 방식 확정
- [ ] 이메일 발송 공급자와 발신 도메인 확정
- [ ] 세무전문가 검수 책임자와 SLA 확정
- [ ] 사용자 프로필 필수항목·동의문구 확정
- [ ] 클라우드·도메인·개발/스테이징/운영 계정 준비
- [ ] OpenAPI·DB·AI Schema 검토 승인
- [ ] 골든셋 100건 준비 계획 확정
- [ ] UAT와 정정 모의훈련 일정 확정
